# Hello REST API Messaging App

## Description
This project demonstrates different REST API calls using Spring Boot.

The application implements multiple REST endpoints to understand how HTTP methods such as GET, POST, and PUT work in a Spring Boot application.

## Technologies Used
- Java
- Spring Boot
- Maven
- REST API
- Git & GitFlow
